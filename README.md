# 💰 Expense Tracker Web Application

A secure, full-stack web application built with **PHP (PDO)**, **MySQL**, and **Bootstrap 5** to help users efficiently manage daily finances, track expenses, handle loans, and secure their user accounts.

---

## 🚀 Key Features

* **📊 Expense & Income Tracking:** Record, monitor, and categorize daily financial transactions.
* **🏷️ Category Management:** Organize transactions into custom categories for clear financial insights.
* **💳 Loan Management:** Keep track of borrowings, lendings, and repayment schedules seamlessly.
* **🔐 Secure Authentication:** Implemented secure password hashing (`password_hash` & `password_verify`) and active session management.
* **✉️ Multi-Step Password Recovery (OTP):** Secure account recovery flow featuring 6-digit OTP verification.
* **🛡️ Advanced Security Logic:** 
  * OTP Expiration limit (5-minute timeout).
  * Brute-force protection (maximum 3 invalid attempt limits before locking the session).
* **🎨 Modern UI/UX:** Fully responsive interface designed with Bootstrap 5, featuring a clean glass-morphism login layout and aesthetic workspace background.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
* **Backend:** PHP (Object-Oriented Database Interactions via PDO)
* **Database:** MySQL (Relational Database Management)
* **Server Environment:** XAMPP / WAMP (Localhost) / Apache
